管理区分：公開用台帳

## この台帳の目的

Pina Studioの運営に使用している外部サービス、役割、依存関係、停止時の影響を一覧化し、障害・契約切れ・アカウント紛失・引き継ぎ漏れを防ぐ。

このファイルは公開リポジトリへ保存できる情報だけを記録する。

## 絶対に記録しない情報

このファイルには、以下の実値を記録しない。

- APIキー
- シークレット
- アクセストークン
- パスワード
- 多要素認証の復旧コード
- 個人のメールアドレス
- 電話番号
- 氏名・住所
- クレジットカード情報
- 銀行口座情報
- Stripeの秘密鍵やWebhook署名シークレット
- Supabaseのservice role key
- Railway・Vercel等の環境変数の値
- 秘密情報を保存している具体的なファイル名や端末内パス

管理者アカウント、多要素認証、支払方法、復旧情報などは、公開リポジトリとは別の非公開台帳で管理する。

## 状態の表記

- `確認済み`：管理画面または実際の設定で確認済み
- `一部確認済み`：利用は確認できるが、契約・権限等が未確認
- `未確認`：リポジトリや運営記録だけでは確認できない
- `未使用`：現在の本番運営では使用していない
- `停止候補`：利用状況を確認後、不要なら停止する

## サービス間の主な依存関係

### 通常のサイト表示

利用者  
→ ドメイン・DNS  
→ Vercel  
→ HTML・JavaScript

### ログイン・ユーザー情報

利用者  
→ Vercel上の画面  
→ Supabase Auth・Database

### 動画生成

利用者  
→ Vercel  
→ Supabaseで認証・クレジット確認  
→ OpenAI等で安全判定  
→ OpenRouter  
→ Seedance  
→ Supabaseへ履歴保存  
→ 必要に応じてRailwayでウォーターマーク処理  
→ 利用者へ表示

### 決済

利用者  
→ Stripe Checkout  
→ Stripe Webhook  
→ Vercel API  
→ Supabaseへ契約・クレジット反映

### 問い合わせ

利用者  
→ 問い合わせフォーム  
→ 問い合わせ受信先  
→ 運営者が確認・対応
